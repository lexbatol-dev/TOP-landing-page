# Byte Bites — Landing Page

A landing page built as part of [The Odin Project's](https://www.theodinproject.com/lessons/foundations-landing-page) Foundations course, practicing CSS Flexbox layout.

**Byte Bites** is a fictional meal-kit delivery service for developers who forget to eat while buiding/debugging. The content and branding are fictional, built specifically as a practice for this project.

## Live Preview

Open `index.html` in your browser, or use a local server (e.g. VS Code Live Preview).

## What I practiced

- Flexbox layout (`flex-direction`, `justify-content`, `align-items`, `flex-wrap`, `flex-grow`/`flex-shrink`/`flex-basis`)
- Block vs. flex layouts
- Centering techniques: `margin: 0 auto` + `max-width` for boxed content vs. full-width backgrounds
- Semantic HTML (`header`, `figure`/`figcaption`, `blockquote`/`footer`)
- CSS specificity and selector scoping (avoiding accidental selector clashes)
- Image optimization: sizing and compression

## Built with

- HTML5
- CSS3 (Flexbox)
- Custom SVG logo
